# vkusvill-Как подключить:
1️⃣ Зарегистрируйте ИИ-агента на vkusvill.ru/oauth/registration/
2️⃣ На почту придёт письмо с данными для подключения, сохраните его
3️⃣ Откройте Claude Code (вкладка Code в приложении Claude). В обычном чате Claude у меня так и не заработало
4️⃣ Скопируйте и отправьте Claude этот текст, вставив в него данные из письма:

«Подключи MCP-сервер ВкусВилла. Вот мои данные из письма: [вставьте сюда]. Документация: https://github.com/vkustech/vkusvill-mcp-server-manifest. Учти, что у ВкусВилла есть баг: после входа он снова просит авторизоваться. Сервер не принимает scope offline_access и принимает только client_secret_post. Настрой подключение так, чтобы это обойти.»

5️⃣ Claude откроет страницу входа ВкусВилла. Войдите и нажмите «Разрешить»
6️⃣ Проверьте: «покажи мои заказы во ВкусВилле» ✅
